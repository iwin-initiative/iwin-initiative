# IWIN Central Registries Directory

This directory hosts the official open-source dictionaries for the International Wine Identification Number (IWIN). 

### Directory Structure (Work in Progress)
* `/countries/` - ISO-mapped country folders containing region, appellation, and producer mapping matrices.

To learn how to submit data or automate the ingestion of official government datasets (such as EU eAmbrosia or US TTB), please refer to the main [CONTRIBUTING.md](../CONTRIBUTING.md) guide.
